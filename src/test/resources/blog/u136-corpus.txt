# U-136 — 판 비교(SentenceAligner) 시험 글 48건 · 기대 결과 라벨
# 계획 2026-11-11-b1-blog-core §8.1 3 · §9 U-136. Claude가 지어 쓴 한국어 글이다(운영 데이터 0).
# 라벨은 SentenceAligner 구현 전에 쓰고 따로 커밋했다 — 구현 뒤 결과에 맞춰 고치지 않는다(드리프트 규칙).
#
# 형식
#   == <id> <갈래> · <설명>
#   - <옛 문장>        (위에서부터 s1, s2, …)
#   + <새 문장>        (새 글의 문장 순서)
#   = <토큰> …         (새 문장마다 하나, 공백으로)
# 토큰
#   s1      그 옛 문장이 글자 그대로(옮김 포함)
#   s1~     그 옛 문장을 고침(같은 주소 · 판+1)
#   s1+s2   옛 문장들을 하나로 합침(어느 쪽이 주소를 잇든 — 나머지는 그 주소로 합쳐짐)
#   s1/     그 옛 문장이 나뉜 조각(주소를 잇는 조각이든 split_from 조각이든)
#   +       새로 쓴 문장
# 어느 토큰에도 없는 옛 문장 = 지운 문장(묘비).
