## 1. 서비스 이용약관 — 「대화」 조 문안

> PR-2(2026-09-19)에서 「대화」를 `terms.html` 제10조로 넣고 문의를 제11조로 밀었다. 아래 문안과 약관 본문은 같아야 한다.
> 이 문서에서는 번호 대신 「대화」 조·「문의」 조로 부른다. 1항의 「대화 기능을 제공하는 경우」는 기능이 킬스위치로 꺼져 있는 동안에도
> 약관이 사실과 어긋나지 않게 넣은 한정어다(설계 §9).

1. 서비스는 토스 미니앱에서 대화 기능을 제공하는 경우, **서로 팔로우한 이용자 사이**에만 1:1 대화(이하 "대화")를 제공합니다. 한쪽이 팔로우를 취소하면
   기존 대화는 읽기만 할 수 있고, 다시 서로 팔로우하면 이어서 쓸 수 있습니다. 어느 한쪽이 상대를 차단하면 대화는 종료됩니다.
2. 대화는 무료이며, 유료 기능이나 결제는 없습니다.
3. 이용자는 대화에서 다음 행위를 해서는 안 됩니다.
   - 성매매·조건만남을 권유·알선하거나 음란한 내용을 보내는 행위
   - 금전·상품권·가상자산을 요구하거나 투자·대출을 권유하는 행위
   - 광고·홍보·도박 등 불법 정보를 보내거나 외부 채널로 유도하는 행위
   - 상대가 원하지 않는데 연락처 등 개인정보를 요구하거나 공개하는 행위
   - 욕설·혐오·협박·스토킹 등 상대를 괴롭히는 행위
4. 이용자는 대화방에서 상대를 즉시 **신고**하거나 **차단**할 수 있습니다.
5. 서비스는 신고를 확인해 제3조의 계정과 별도로 대화 기능 이용을 **경고 → 7일 정지 → 영구 정지** 순으로 제한할 수 있습니다.
   서로 다른 두 이용자에게 신고된 경우, 운영자가 확인하기 전이라도 대화 기능이 7일간 자동으로 정지됩니다.
   위반이 중대하면 단계를 건너뛰고 영구 정지할 수 있습니다.
6. 대화 내용은 신고 확인과 법령상 협조를 위해 **암호화하여 저장**합니다. 보관 기간과 삭제는 개인정보처리방침을 따릅니다.

## 2. 운영정책 — 신고 대응 프로세스

| 단계 | 내용 |
|---|---|
| 접수 | 대화방 상단 「신고」 원탭 — 기존 신고와 같은 사유 선택 + 상세 입력. 신고 시 해당 대화방 식별자가 함께 저장된다 |
| 알림 | 운영자 관리 화면(`/admin`)에 미처리 신고 수 배너. 운영자 토스 계정 연결 시 운영자에게 푸시 |
| 확인 | 운영자가 관리 화면에서 **신고된 대화방의 신고 시점까지의 대화 기록**을 열람한다. 신고 뒤에 오간 대화와 신고가 없는 대화방은 열람할 수 없다(같은 신고자가 처리 뒤 다시 신고하면 그 시점까지로 넓어진다) |
| 조치 | 무혐의 / 경고 / 7일 정지 / 영구 정지 중 하나를 적용하고 신고를 「처리 완료」로 닫는다 |
| 목표 시간 | 접수 후 **영업일 2일 이내** 조치 |
| 자동 조치 | 대화방 신고 중 처리 전인 신고의 서로 다른 신고자 2명 이상 → 운영자 확인 전 대화 기능 7일 자동 정지(운영자가 해제·연장 가능). 프로필 신고는 세지 않는다. 무혐의로 처리해도 자동 정지는 그대로이니 풀려면 제재 해제를 따로 한다 |
| 신고자 통지 | v1에서는 처리 결과를 따로 통지하지 않는다 |

## 3. 제재 정책

| 단계 | 기준 | 효과 |
|---|---|---|
| 경고 | 경미한 첫 위반(가벼운 광고성 메시지, 무례한 표현 등) | 대화 가능. 다음 위반 시 정지로 올라간다 |
| 7일 정지 | 반복 위반, 또는 서로 다른 신고자 2명 자동 조치 | 7일간 새 대화방 열기·메시지 발송 불가(기존 메시지 읽기는 가능) |
| 영구 정지 | 성매매·조건만남, 금전 사기, 불법 광고, 정지 후 재위반 | 대화 기능 영구 이용 불가. 독서 기록 등 다른 기능은 유지 |

- 정지 중인 이용자와의 대화방은 양쪽 모두 읽기 전용이 되고, 그 이용자는 새 대화방을 열 수 없다.
- 제재에 이의가 있으면 이용약관 「문의」 조의 이메일로 요청할 수 있고, 운영자가 대화 기록을 다시 확인해 해제할 수 있다.

## 4. 불법 행위 방지 조치

1. **맞팔 게이트** — 서로 팔로우해야만 대화방이 열린다. 모르는 사람이 먼저 메시지를 보낼 수 없어 스팸·조건만남 광고의 입구가 없다.
   자격은 메시지를 보내고 열 때마다 서버가 다시 확인한다.
2. **발송 제한** — 메시지 1분 60건, 새 대화방 1시간 10개. 넘으면 서버가 거부한다.
3. **원탭 신고·차단** — 모든 대화방 상단. 차단 즉시 대화방이 종료되고 양쪽 목록에서 사라진다.
4. **연락처·링크 감지 표시** — 전화번호·메신저 아이디·외부 링크로 보이는 메시지에 표시를 붙이고, 받는 사람의 대화방 상단에
   「연락처·외부 링크·금전을 요구하는 상대는 신고해 주세요」 안내를 띄운다(그런 메시지가 대화에 남아 있는 동안 계속). 발송 자체는 막지 않는다(오탐 방지 — 처리는 신고·제재가 맡는다).
5. **제재** — §3.
6. (확장) AI 메시지 검사 스위치가 준비돼 있다. 월 신고 5건 이상이거나 토스가 요구하면 켠다(켜기 전 개인정보처리방침의 국외이전 항목을 먼저 개정한다).

## 5. 개인정보·메시지 보호

- **최소 수집**: 대화 기능이 새로 저장하는 것은 대화방(두 참여자 식별자·상태·참여자별 숨김 여부·마지막으로 읽은 위치·마지막 새 메시지 알림 시각)과
  메시지(보낸 사람·본문·시각·연락처/링크 감지 여부), 그리고 제재 기간(정지 종료·영구 정지 시각)뿐이다. 신고에는 대화방 식별자·처리 상태·조치가 더해진다.
  성별·위치·연락처·사진은 받지 않는다(v1은 텍스트만). (PR-2에서 코드와 대조해 항목을 채움 — 처리방침 §2와 같은 목록.)
- **암호화**: 메시지 본문은 **AES-256-GCM**으로 데이터베이스 컬럼 단위 암호화. 키는 데이터베이스·백업과 분리해 SSM 암호화 항목(SecureString)으로 관리한다(배포 때 서버 환경 파일로 전달된다).
- **보관·삭제**
  - 회원 탈퇴 시 그 이용자가 참여한 대화방과 메시지를 **즉시 삭제**한다.
  - 차단으로 종료된 대화방은 **30일 뒤 삭제**한다. 신고된 대화방은 신고 처리가 끝날 때까지 삭제하지 않는다.
  - 「나가기」는 내 목록에서만 숨긴다(상대에게 알리지 않음). 상대가 새 메시지를 보내면 다시 보인다.
- 처리방침: `https://booktimer.app/privacy`

## 6. 수사기관 협조

- 창구: 서비스 문의 이메일(이용약관 「문의」 조).
- 적법한 요청(영장 등)이 오면 해당 대화방 기록을 텍스트로 내보내 제출한다. 요청 대상 대화방은 **법적 보존** 표시를 해 자동 삭제에서 제외한다.
- 보존 요청을 받으면 **즉시** 해당 대화방 기록을 텍스트로 내보내 별도로 보관한다. 이후 당사자가 탈퇴해도 제출용 기록은 남는다
  (회원 탈퇴 시 대화방·메시지 즉시 삭제는 그대로다 — 법적 보존은 자동 삭제만 막는다).
- 법적 보존 중인 신고는 관리 화면에서 삭제할 수 없다(삭제하면 보존이 풀려 다음 자동 삭제에 방이 지워지므로, 보존을 먼저 해제해야 한다).

## 7. 토스 통지 대응

- 앱인토스로부터 위반 통지·수정 요청을 받으면 **48시간 이내** 답변하고, 필요하면 킬스위치(`booktimer.chat.enabled=false`)로 대화 기능을 즉시 끈다.

## 새 메시지 푸시 — 콘솔 등록 문구 (PR-3에서 등록)

> 콘솔 기능성 템플릿은 **등록 즉시 AI 검수 → 승인되고 이후 수정·삭제가 불가**하며, 테스트 발송은 등록된 템플릿으로만 된다.
> 그래서 대화함 착지 경로(`?chat=inbox`)가 생긴 PR-3에서 등록하고 곧바로 테스트 발송으로 도착 화면까지 확인한다
> (2026-09-19 사용자 결정 — 8월에 착지 경로를 나중에 붙이느라 v1 템플릿 3개를 버린 전례). 운영자 알림 템플릿은 PR-2 때 따로 정한다.

| 항목 | 값 |
|---|---|
| 동의문 (CONDITION_BASED) | 이름 「대화 알림 동의문」 · 질문 「새 메시지가 오면 알려드릴까요?」 · 발송 시점 「서로 팔로우한 사람이 보낸 새 메시지가 도착했을 때(같은 대화방은 30분에 한 번까지)」 |
| 템플릿 (type SERVER, FUNCTIONAL) | 이름 「새 메시지 푸시 v1 (대화함 착지)」 · 코드 `booktimer-dm-message`(입력란은 `booktimer-` 접두 고정 — 뒤만 적는다) |
| 제목 / 내용 | 「새 메시지」 / 푸시 「새 메시지가 도착했어요. (북타이머 알림)」 · 인박스 「새 메시지가 도착했어요.」 |
| 이동 | `intoss://booktimer/?chat=inbox` |
| 보낸 사람 표시 | 넣지 않는다 — 잠금 화면에 대화 상대가 드러나지 않게 |
| 점등 SSM | `/booktimer/TOSS_DM_MESSAGE_ENABLED`·`/booktimer/TOSS_DM_MESSAGE_TEMPLATE_CODE` → env `BOOKTIMER_TOSS_DM_MESSAGE_*` |

## 채널톡 제출 (PR-3 출시 직전)

제출물: 이 문서의 §1~§7을 그대로 붙인다. 함께 적을 것 — 미니앱 ID 61047, 기능이 「서로 팔로우한 이용자 간 1:1 텍스트 대화」라
주의사항의 채팅 서비스 정의(지인 또는 ID 기반으로 특정 사용자와 메시지)에 해당한다고 판단한 근거, 킬스위치로 즉시 끌 수 있다는 점.
접수 회신에 만남·소개팅 재분류 언급이 없으면 설계 원장 U-1 충족.
