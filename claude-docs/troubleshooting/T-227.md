# T-227 · 커밋 게이트의 `./gradlew test`가 admin·토큰 계열 8건을 「expected 2 but was 8」류로 떨구는데, 소스를 한 글자도 안 고치고 재실행하면 전부 초록이다 — 순서 의존 오염이라 내 diff는 무죄다**) / **1회차

증상: 독서/공부 상호배타 가드(PR #1033)를 커밋할 때 게이트가 `AdminStatsServiceTest`·`AdminUserServiceTest`·`ApiTokenServiceDetachedUserTest` **8건**을 실패시켰다. 단언은 전역 count 계열(`expected 2 but was 8` 등)로, **기대값보다 실제값이 크다**. 소스 무변경 상태로 재실행하니 **237클래스 2,212건 전부 green**(그 사이 변경은 문서 2줄뿐). / 원인: 전역 count를 단언하는 `@Transactional` 테스트에 **다른 테스트가 커밋한 행이 샌다**(테스트 간 격리 실패). 롤백되지 않는 경로(별도 트랜잭션으로 커밋하는 테스트)가 앞서 돌면 뒤 테스트의 count가 부푼다 — 그래서 실행 순서에 따라 빨간불이 됐다 안 됐다 한다. ⚠️ **어느 테스트가 커밋하는지는 특정하지 못했다.** / 해결: **소스 변경 없이 `./gradlew test` 1회 재실행** → green. 게이트가 통과하면 그대로 커밋한다. / 재발방지: 이 패턴(**admin·토큰 계열 + 전역 count 단언 + 실제값이 기대값보다 큼**)을 만나면 **자기 diff를 뒤지기 전에 재실행 1회를 먼저** 한다 — 사라지면 이 항목이다. ⚠️ **이 항목의 값은 해결이 아니라 「내 변경이 깬 게 아니다」를 빨리 알려 주는 것**이다(원인 미특정이라 *해결* 필드가 얇은 것은 의도된 상태다). **2회차를 만나면 원인 특정을 별도 작업으로 승격**한다 — 후보 절차: `--tests`로 admin 계열만 단독 실행해 초록인지 보고(초록이면 오염원은 밖에 있다), `build/test-results/test/*.xml`의 타임스탬프로 직전에 돈 테스트를 좁힌 뒤 그 테스트의 커밋 경로를 찾는다. / **관련**: T-078(같은 게이트가 gradle hang으로 막히는 다른 고장 — 증상이 「멈춤」이면 그쪽, 「빨간불」이면 이쪽
