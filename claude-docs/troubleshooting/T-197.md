# T-197 · 어제까지 되던 dev 포트가 「OS 예약」으로 안 뜬다 — Windows 동적 포트 예약은 부팅마다 달라진다

증상: 재부팅 뒤 미니앱 목 모드를 띄우니 `preview_start`가 **Port 5174 is reserved by the OS**로 거절했다. 코드·설정은 한 글자도 안 바뀌었고 5174는 CLAUDE.md에 적힌 표준 포트다. / 원인: **Windows(Hyper-V·WinNAT 등)가 부팅 시 동적 포트 구간을 통째로 예약**한다. `netsh interface ipv4 show excludedportrange protocol=tcp`로 보니 **5118~5217**이 잡혀 있었고 5174가 그 안이다. 예약 구간은 **부팅마다 자리가 바뀌어** 어제 되던 포트가 오늘 막힌다 — 앱·vite·레포 어디에도 원인이 없어 설정을 뒤지면 영영 안 나온다. / 해결: 예약 밖 포트(5300)로 옮기되 **추적 파일인 `miniapp/vite.config.ts`의 `server.port`는 건드리지 않는다** — 예약 구간은 이 PC의 이번 부팅 사정이지 레포에 박을 값이 아니다. 대신 **머신 로컬(gitignore)인 `.claude/launch.json`**의 `runtimeArgs`에 `"--", "--port", "5300"`을 얹고 `port`도 맞춘다(`npm run` 뒤 `--`가 있어야 인자가 vite까지 간다). / 재발방지: 「어제까지 되던 포트가 안 열린다」면 **앱·설정을 뒤지기 전에 `netsh ... show excludedportrange`를 먼저 본다.** 고칠 자리는 레포가 아니라 gitignore된 `launch.json`이다 — 여기를 고쳐야 다음 부팅에 또 옮겨도 커밋이 안 생긴다. **관련**: T-184 군(「앱이 고장났다」로 보이지만 실은 관측·실행 환경의 성질)
