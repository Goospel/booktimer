# T-218 · 소스 문자열 단언은 「존재」가 아니라 「건수·전체 인자열」로 잡는다 — `toContain('식별자')`는 선언문에 걸려 배선을 통째로 지워도 초록이다(무계측 배선)

**2회차(2026-09-01 공부 서재 PR-2 리뷰 W3 재발 — 그때는 이름만 붙였고 이번에 부류로 굳었다)** / 증상: 타이머–책 연결 3개 PR(#1010·#1011·#1013)의 독립 리뷰가 돌연변이를 재주입하자 **8종이 전 스위트 초록인 채 생존**했다 — App→MainTabs 프롭 전달을 통째로 지워도(`toContain('setStudyBookId')`가 `useState` **선언문**에 걸려 통과), `timerStartBookId(…)`의 셋째 인자를 독서 슬롯 `homeBookId`로 바꿔도(`toContain('startStudy(timerStartBookId(')`가 여는 괄호까지만 재서 통과 — 설계가 「그럴듯한 사고 ②」로 이름까지 붙인 결함이고 `tsc`도 통과), 와이어 키 `bookId`→`book`으로 바꿔도(목 왕복 테스트가 `mockRequest`를 직접 불러 클라이언트 함수의 body를 한 번도 안 지남), 홈 기본 선택 호출을 `null`로 굳혀도, 교체 성공 경로의 `onStudyChange(next)`·교체 토스트의 `mode`·`body.study-mode`의 `--accentPill` 선언을 지워도 초록이었다. 구현자는 매 PR 돌연변이 4~5종을 「전부 사살」로 보고했는데 **자기가 고른 돌연변이만 죽였을 뿐** 리뷰어가 고른 것은 살아 있었다. / 원인: 정적 렌더 하니스(jsdom 없음, T-149)라 배선을 **소스 문자열**로 잠그는데, 그 단언이 ① 식별자 **존재**만 봐서 선언문·다른 호출부에 걸리고 ② 호출의 **머리만** 봐서 인자 교체를 못 보고 ③ 목 왕복이 클라이언트 함수를 **우회**해 전송 형태를 안 보며 ④ 순수 함수 테스트는 「화면이 그 함수를 부르는지」를 모르고 ⑤ 마크업 단언은 `var(--token, 폴백)` 도입 뒤 폴백 리터럴이 늘 실려 되살릴 수 없다. 다섯 다 「테스트가 초록 = 배선이 있다」를 말하지 않는다. / 해결: ① 배선 단언은 **건수**(`match(/setStudyBookId/g)).toHaveLength(2)` = 선언 + 전달)나 **전체 인자열**(`'startStudy(timerStartBookId(study.books ?? [], study.recentBookId ?? null, studyBookId))'`)로 ② 전송 형태는 `api.ts` 소스에서 `request('/api/…', { body: { bookId } })`를 그대로 ③ 화면이 함수를 부르는지는 정적 렌더에 실리는 속성(`data-selected-book`)으로 ④ CSS 토큰은 마크업이 아니라 css 블록 슬라이스에서 **선언 자체**를 단언. 전부 붙인 뒤 같은 돌연변이를 재주입해 **각각 정확히 한 단언만** 죽는 것을 확인했다(주입·되돌림은 grep 건수로 단언). / 재발방지: ① **소스 문자열 단언을 쓸 땐 「이 문자열이 선언문·다른 호출부에도 매치되는가」를 먼저 묻는다** — 매치되면 건수나 전체 호출식으로 좁힌다. ② **돌연변이는 구현자가 아니라 리뷰어가 고른다** — 구현자의 「N종 전부 사살」은 자기 계측기의 사각을 재지 못한다(같은 가정을 공유하므로). 밝은선 리뷰(±150줄)의 돌연변이 재실측이 이 부류를 3개 PR에서 연속으로 잡았다 — 리뷰 게이트의 값이 실측으로 증명된 자리다. ③ 목 왕복 테스트는 **클라이언트 함수(`startStudy`)를 통해** 부른다 — `mockRequest`를 직접 부르면 목이 계약을 아는지만 재고 클라가 계약을 지키는지는 안 잰다. ④ 곁다리(관측 경로 — T-184 군 11·12회차): `preview_start`는 `.claude/launch.json`을 **세션 cwd**에서 찾아 워크트리 세션이면 남의 워크트리 서버를 띄우고, 다른 세션이 공용 `seed` 탭을 자기 포트로 돌린다 — 둘 다 「내 변경이 화면에 없다」로 나온다. 판별은 `location.href` + `fetch('/src/<파일>')`에 신규 **ASCII 식별자** 유무(한글 리터럴은 esbuild가 `\uXXXX`로 이스케이프해 못 쓴다), 처방은 그 워크트리에서 `npm --prefix miniapp run dev:mock -- --port <고유>` + `tabs_create`로 전용 탭. ⑤ 곁다리 2: 리베이스로 두 커밋(행 추가 → 같은 행 보강)을 옮기면 `merge=union`이 초판·최종본을 **둘 다** 남긴다 — 이번 3개 PR에서 **2회** 났다(T-210 재발, 훅이 push에서 막았다). / **관련**: T-149(정적 렌더라 부정 단언 금지 — 이쪽은 긍정 단언도 공허할 수 있다는 후속) · T-212(계측기가 대상을 안 잡아도 초록) · T-184(관측 경로 군) · T-210(changelog union 중복))
