# T-090 · Windows preview `launch.json`으로 `gradlew bootRun` 못 띄움 — `cmd /c <절대경로>gradlew.bat -p <절대경로> bootRun`

**증상**: `runtimeExecutable: "gradlew.bat"`(상대경로)은 "내부/외부 명령이 아님" 에러로 즉시 실패. `cmd /c gradlew.bat`로 감싸도 cwd가 안 맞아 또 실패.

**원인**: preview가 PATH에서 `.bat`을 찾는데 cwd가 워크트리 루트라는 보장 없음.
⚠️ **정정 (2026-09-30)**: cwd가 맞아도 실패한다. Claude Code가 자기 프로세스 환경에 `NoDefaultCurrentDirectoryInExePath=1`을 켜 두어(사용자·시스템 환경변수엔 없다) cmd가 **현재 폴더를 실행 파일 탐색에서 뺀다**. 대조 실측 — 워크트리 루트에서 `cmd /c "gradlew.bat --version"`: 변수 켜짐 → `'gradlew.bat' is not recognized`, 같은 셸에서 변수만 지우고 → `Gradle 9.7.1`. 그래서 처방의 핵심은 「cmd 경유」가 아니라 **전체 경로**다.

**해결 / 예방**:
```json
{
  "runtimeExecutable": "cmd",
  "runtimeArgs": ["/c", "<절대경로>\\gradlew.bat", "-p", "<워크트리 절대경로>", "bootRun"]
}
```
`.bat`은 cmd 셸 경유 필수 + 절대경로로 cwd 의존 제거 + `-p`(gradle `--project-dir`)로 프로젝트 디렉토리 고정. `bootRun`은 무겁다(빌드+MySQL Docker) — SSR fragment 로드순서처럼 정적 mock으론 못 잡는 검증에만 쓰고, 순수 로직·반응성은 N-117 static-preview 우선. `.claude/launch.json`은 gitignore라 커밋 안 됨.

**관련**: N-117(static-preview), T-078(gradle 데몬 경합), T-086(Docker 누적).

- **누적 갱신** (2026-06-25): Windows에서 preview `launch.json`으로 `gradlew bootRun`을 못 띄움 — `runtimeExecutable: "gradlew.bat"`(상대경로)은 "내부/외부 명령이 아님" 에러로 즉시 실패(preview가 PATH에서 찾고 cwd가 워크트리 루트라는 보장 없음), `cmd /c gradlew.bat`로 감싸도 cwd가 안 맞아 또 실패 / 해결=`runtimeExecutable: "cmd"` + `runtimeArgs: ["/c", "<절대경로>\\gradlew.bat", "-p", "<워크트리 절대경로>", "bootRun"]` — `.bat`은 cmd 셸 경유 필수 + 절대경로로 cwd 의존 제거 + `-p`(gradle `--project-dir`)로 프로젝트 디렉토리 고정 / 단 `bootRun`은 무겁다(빌드+MySQL Docker) — SSR fragment 로드순서(`<use>`+`<symbol>` 같은 문서 의존)처럼 정적 mock으론 못 잡는 검증에만 쓰고, 순수 로직·반응성은 N-117 static-preview 우선 / 검증 후 8080 반납·`docker stop/rm`으로 컨테이너 정리(T-086) / `.claude/launch.json`은 gitignore라 커밋 안 됨, 절대경로는 그 워크트리 전용이라 stale 무해 / N-117·T-078(gradle 데몬 경합)·T-086(Docker 누적)
- **2회차** (2026-09-29): 데스크톱 세션이 커밋 게이트 hang(#1219) 우회용으로 gradle 데몬을 미리 띄우려다 `cmd /c ... gradlew.bat`이 「내부 또는 외부 명령이 아닙니다」로 실패 → PowerShell `Start-Process -FilePath "<워크트리>\gradlew.bat" -ArgumentList '-p',"<워크트리>",…`(전체 경로)로 우회.

Git Bash의 `./gradlew`는 해당 없다(셸이 경로로 연다).
