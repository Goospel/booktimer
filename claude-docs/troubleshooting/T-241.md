# T-241 · 선행 가드를 새로 끼우면 그 뒤 게이트를 겨눈 기존 테스트가 조용히 공허해진다 — 충돌도 실패도 없이 초록인 채, 자기 게이트에 닿지도 못한다

**1회차(공허한 테스트 군 8회차)** / 증상: API 부정접근 감사 후속(#1099)에서 공개 책방 구매 링크 4개(`/u/{loginId}/books/{bookId}/buy*`)에 `profileService.resolveVisibleTarget(viewer, loginId)`(차단·ADMIN·없는 아이디)를 **앞단에** 끼우고 서비스 조회를 `findByIdAndUser`로 스코프했다. 신설 테스트 10건 RED→GREEN, 구현자 돌연변이 6종 전부 사살, 전체 2,282건 초록. 그런데 `reviewer`가 돌연변이를 다시 골라 넣자 둘이 살아남았다 — ① 교보의 `!book.isPublic()` 게이트를 떼도 **59건 전부 초록**, ② 쿠팡·Yes24·교보 3곳의 `findByIdAndUser`를 `findById`로 되돌려도 **7클래스 87건 전부 초록**. ①의 뿌리는 기존 「비공개 책 게이트」 테스트 4건(`BookControllerTest`·`CoupangBuyControllerTest`·`Yes24BuyControllerTest`·`KyoboBuyControllerTest`)이 경로 loginId를 존재하지 않는 `"somehandle"`로 쓴 것이다 — 변경 전엔 loginId가 안 쓰여 게이트까지 갔지만, 이제 새 가드가 **먼저** 빈 값을 돌려줘 **테스트가 게이트에 닿지 않는다**. 이름은 「비공개면 막힌다」인데 검증하는 것은 「없는 핸들이면 막힌다」가 됐다. 교보는 서비스 단위 테스트가 원래 없어(설계 U-2가 적어 둔 사실) 공개 게이트 커버리지가 **0**이 됐다. ②는 구현자가 소유자-스코프 돌연변이를 **알라딘 한 곳에만** 넣고 「4경로가 한 번에 닫힌다」로 일반화한 것이다. / 원인: **새 선행 가드가 기존 테스트의 픽스처를 「가드에 걸리는 값」으로 바꿔 버린다.** 옛 테스트는 자기 게이트만 겨눠 픽스처를 최소로 잡았고(loginId는 안 쓰이니 아무 값), 그 최소 픽스처가 새 가드의 거부 조건과 겹치면 테스트는 **이름과 다른 경로**로 초록이 된다. 실패도 충돌도 없다 — 거부 결과(리다이렉트)가 원래 기대값과 같아서다. 돌연변이 확인이 못 잡은 것은 구현자가 **새 테스트만** 겨눴기 때문이다(옛 테스트가 아직 자기 게이트에 닿는지는 아무도 안 물었다). 이 군의 앞선 그물 셋(돌연변이·전제 의심·RED 산술)이 전부 놓치고 **독립 리뷰의 재선정 돌연변이**가 잡은 두 번째 사례다(첫째는 T-205). / 해결: 네 테스트의 `"somehandle"`을 **책 주인의 실제 loginId**로 바꿔 게이트를 다시 통과하게 하고(교보 게이트 제거 돌연변이가 이제 4건을 죽인다), 쿠팡·Yes24 서비스와 교보 컨트롤러에 소유자-스코프 테스트 3건을 더했다(스코프 되돌림이 3건을 죽인다). 누적 8종 사살. / 재발방지: ① **가드를 앞단에 새로 끼우면, 같은 경로의 기존 테스트가 아직 자기 게이트에 닿는지 돌연변이로 재확인한다** — 새 테스트가 아니라 **옛 게이트를** 제거해 옛 테스트가 붉어지는지 본다. 붉어지지 않으면 픽스처가 새 가드에 걸린 것이다. ② 픽스처는 「이 테스트가 겨누는 게이트 **직전까지** 통과하는 값」으로 잡는다 — 「안 쓰이니 아무 값」은 다음 가드가 생기는 순간 거짓이 된다. ③ **같은 모양의 경로가 N개면 돌연변이도 N곳에 넣는다** — 한 곳에서 죽었다고 형제 경로가 잠긴 것은 아니다(각 경로의 테스트 파일이 다르다). ④ 서비스 단위 테스트가 없는 형제(교보)는 컨트롤러 테스트가 공허해지는 순간 커버리지 0이 된다 — 형제 간 테스트 비대칭을 설계의 미검증 가정에 적어 두면(U-2가 그랬다) 리뷰가 거기부터 본다. / **관련**: T-205(공허한 테스트 군 — 앞선 그물이 전부 뚫리고 독립 리뷰가 잡은 첫 사례) · T-218(구현자의 「N종 전부 사살」은 자기 계측기의 사각을 못 잰다 — 돌연변이는 리뷰어가 고른다) · 글로벌 「통과는 증거가 아니다」(⑤ 양성 대조군 — 옛 테스트의 양성 대조군이 새 가드로 사라졌다)
