# T-245 · 엔티티 필드 삭제와 컬럼 drop을 같은 배포에 넣으면 블루/그린 교대 창 동안 옛 컨테이너가 없어진 컬럼을 SELECT해 인증 요청이 전부 500이 난다 — 이 레포는 V88 때 알고 피했는데, 그 지식이 changelog·마이그레이션 주석에만 있어 다음 설계가 다시 한 PR에 묶었다

**1회차(사고 전 차단)** / 증상: 공부 「하루 목표」 서버 잔재 정리(PR-5, #1132 초판)가 설계(2026-09-13 `claude-docs/plans/…per-book-session.md` §5 「PR-5 = V92 drop + 코드 삭제」)대로 `User.studyDailyGoalSeconds` 삭제와 `V92__drop_study_daily_goal.sql`을 한 커밋에 담았다. TDD·전체 스위트 2356건·돌연변이 전부 초록이었고, 머지 전 필수 독립 리뷰(밝은선 ① Flyway)가 **머지 보류**로 막았다. / 원인: `deploy/deploy-on-ec2.sh`는 옛 컨테이너가 트래픽을 받는 채로 새 컨테이너를 띄우고(Flyway는 새 컨테이너 기동 시 실행) 헬스 통과 뒤에야 옛 것을 `stop`한다. 그 창에서 옛 이미지의 Hibernate는 `users`를 로드할 때 매핑된 모든 컬럼을 SELECT하므로 `CurrentUserService`·`BookTimerUserDetailsService`의 `findByLoginId`가 `Unknown column`으로 죽는다. 옛 컨테이너의 readiness는 DB를 보지 않아(`probes.enabled`만 켠 기본 그룹 — 리뷰어 판단, 운영 미실측) healthy로 남아 Caddy(`lb_policy first`)가 빼지 않는다. 테스트는 원리상 못 잡는다 — 스위트는 한 이미지·한 스키마만 본다. 리뷰어 재현: merge-base의 `User`(필드 있음) + Flyway V92까지 적용한 H2 + `ddl-auto=none` → `findByLoginId`가 `SQLGrammarException: Column "U1_0.STUDY_DAILY_GOAL_SECONDS" not found`. / 해결: V88(#1070 코드 → #1077 drop)과 같이 둘로 갈랐다 — PR-5a(#1132)는 코드만 지워 머지·배포(컬럼은 `DEFAULT 0`이라 새 코드 INSERT에 무해 — V92를 뺀 `FlywayMigrationTest` 22건 통과), PR-5b는 배포된 컨테이너 이미지가 PR-5a 머지 커밋임을 확인한 뒤 V92 + 컬럼 부재 단언(V92 없이 Red 1건 → 넣고 23건 Green)을 올렸다. / 재발방지: hookify warn 룰 `.claude/hookify/warn-migration-drop-two-deploys.md` — `db/migration/V*.sql`에 `alter table … drop [column] <이름>`(한 문장 안의 여러 절 포함, index·key·foreign·constraint·primary·check 제외)이나 `drop table`을 쓰면 「코드 삭제가 이미 배포돼 떠 있는가 / 같은 PR이면 drop을 다음 배포로」와 착수 게이트(ECR `imageTag=<sha>` 다이제스트 대조)·롤백 주의를 띄운다. `-Validate` 오류 0 · 양성 대조(V92 Write 시 발동) · 판별력(기존 마이그레이션 92개 중 9개 매치, 전부 실제 drop — V20·V28·V29·V42·V68·V70·V71·V88·V92) · 샘플 `drop index`·`drop foreign key`·`add column` 비발동. ⚠️ 한계: 파일 쓰기 시점의 경고라 **설계 단계**(계획 md)에서는 안 뜬다 — 이번에 틀린 곳은 설계였다. 룰은 구현이 그 설계를 받아 V 파일을 쓰는 순간에 한 번 더 멈추게 할 뿐이다. / **관련**: V88 파일 헤더(롤백 시 기동은 성공하고 인증 요청만 500 — Flyway `ignoreMigrationPatterns` 기본 `*:future`) · T-168·T-169·T-170(같은 폴더의 `warn-migration-schema-test` 룰 — 스키마 검증은 `FlywayMigrationTest`) · 글로벌 「통과는 증거가 아니다」(전 스위트 초록 ≠ 배포 중 호환).
