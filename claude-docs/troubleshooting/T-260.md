# T-260 · 실러너는 세션을 시작한 체크아웃의 훅을 쓴다 — 메인에서 시작한 세션은 워크트리에서 고친 훅을 머지·pull 전엔 못 돌린다

- **정정** (2026-10-05): 옛 요약은 「데스크톱 워크트리 세션의 러너 cwd·`CLAUDE_PROJECT_DIR`가 메인 체크아웃」이라 했으나, 실측으로 `CLAUDE_PROJECT_DIR`는 세션 시작 폴더이고 상대 경로 훅은 셸의 현재 폴더 기준이었다(T-262). 이제 훅 명령은 `${CLAUDE_PROJECT_DIR}` 기준이다.
