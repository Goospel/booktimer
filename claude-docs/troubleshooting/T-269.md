# T-269 · 전체 페이지 캡처는 고정 요소 겹침 착시를 만든다

## 증상
재테마 리뷰의 전체 페이지 사진에서 화면 아래 가운데 알약이 본문 중간(카드·버튼)을 덮고 있었다.

## 원인
전체 페이지 캡처는 문서를 한 장으로 이어 붙이고 고정 요소는 캡처 시점 뷰포트 자리에 한 번 그린다 — 사용자가 어느 스크롤 위치에서도 보지 못하는 그림이다. 실제로는 `body.has-rails` padding-bottom이 스크롤 끝에서 맨 아래 콘텐츠를 비켜 준다.

## 해결
뷰포트 캡처와 수치로 다시 쟀다: 스크롤 끝 정적 겹침 0. 대신 스크롤을 스스로 정하는 길(ProseMirror 캐럿 · Tab 포커스)에서 진짜 가림을 찾아 고쳤다.

## 재발 방지
고정 요소가 있는 화면의 겹침은 뷰포트 캡처 + 수치로만 판정한다. 전체 페이지 캡처는 레이아웃 훑어보기용이다.
