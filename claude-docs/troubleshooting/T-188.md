# T-188 · 필터로 흔들린 선을 `border-image`로 쓸 때 두 번 조용히 사라진다 — 축약형 var 중첩과 `round` 반복

증상: 종이·연필 테마에서 연필 테두리가 ① 아예 안 그려지거나 ② 그려져도 **점선처럼 끊겨** 보였다. 둘 다 콘솔 에러 0이고 CSS 파일엔 규칙이 멀쩡히 들어 있어 원인이 안 보인다. / 원인: ① **축약형에 var()를 통째로 넣으면 무효** — `--pencil: var(--pencil-frame) 8 / 8px stretch`처럼 한 벌로 묶고 `border-image: var(--pencil)`으로 쓰면 Chrome이 선언 전체를 버린다(computed에서 `border-image-slice`가 기본값 `100%`로 남는 것이 서명이다). 변수가 또 변수를 품은 중첩이 문제라, **slice·width·repeat은 리터럴로 적고 이미지만 변수로** 받아야 한다. ② **`round`(타일 반복)를 쓰면 이음매마다 선이 어긋난다** — `feDisplacementMap`으로 흔들린 선은 타일 좌우 끝의 높이가 서로 다르므로, 반복하는 순간 경계마다 단차가 생겨 점선으로 읽힌다. / 해결: `border-image: var(--pencil-frame) 8 / 8px stretch`(리터럴 전개 + `stretch`), 타일은 300px로 크게 잡아 stretch 배율을 낮춘다(작은 타일을 크게 늘리면 떨림이 뭉개져 직선이 된다). / 재발방지: ① **`border-image`가 안 먹으면 computed의 `borderImageSlice`를 먼저 본다** — `100%`면 선언이 파싱 단계에서 버려진 것이고, 값이 정상인데 안 보이면 그리기 쪽 문제다. 두 원인은 증상이 같아 이 한 줄로 갈린다. ② **불규칙한 그림을 타일 반복하지 않는다** — 규칙적 패턴만 `round`/`repeat`이고, 흔들린 선·손그림은 `stretch` + 큰 타일이다. ③ `<slice> / <width>` 문법 덕에 **border-width와 그림 폭을 분리**할 수 있다 — border는 1px로 두고 그림만 8px로 그리면 기존 레이아웃을 1px도 밀지 않고 테두리만 갈아끼운다(36개 템플릿에 인라인 `<svg>` 필터를 심는 대안을 피한 근거). 1회차 신규
