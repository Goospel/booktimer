# T-207 · 로드 때 발화하는 색 트랜지션 + 백그라운드 탭 = 화면 전역이 `rgb(0,0,0)`으로 얼어붙는다 — 그 검정은 UA 기본값이라 「TDS 전역이 안 붙었다」로 완벽히 위장한다

**2회차(T-196 재발 — 그때는 「일부만 낡아」 감별됐지만 이번엔 전부 한 값이라 비대칭이 없었다)** / 증상: 목 모드에서 TDS `Text` 21개의 computed `color`가 **전부 `rgb(0,0,0)`**이었다. 의도한 잉크(`#2C2A24`)도, TDS 리셋이 body에 거는 `#212529`도 아닌 **순수 검정**이라 「TDS 전역 스타일이 아예 안 붙었나」가 가장 그럴듯한 가설이 된다. 실제로 스타일시트를 순회해 `body { color: rgb(33,37,41) }` 규칙이 **존재하고 · `disabled:false` · `document.body.matches('body')===true`**임을 확인했는데도 computed는 검정이었다 — 여기서 캐스케이드 이론이 통째로 무너져 한참을 헤맸다. / 원인: `global.css`의 독서등 전환 규칙(`body, body main, body .lamp-page { transition: … color 0.45s ease }`)이 **페이지 로드 때 발화**한다. `html body`가 `color`를 안 잡고 있어서 첫 스타일 계산의 잉크는 UA 기본 **검정**이고, React 마운트 시 TDS가 emotion `<Global>`로 `body { color: #212529 }`를 주입하는 순간 색이 **바뀌어** 트랜지션이 시작된다. 그런데 그 탭이 `visibilityState === 'hidden'`(내부 패널·비활성 확장 탭 둘 다)이라 렌더가 스로틀돼 **트랜지션이 시작값에 얼어붙고**, `getComputedStyle`은 최종값이 아니라 그 보간값 = 검정을 돌려준다. ⚠️ **T-196의 감별 신호(「값이 일부만 낡았다」)가 이번엔 안 통한다** — 잉크는 화면의 **거의 모든 글자**가 상속으로 물려받는 값이라 21개가 전부 같은 검정으로 얼었고, 비대칭이 눈에 안 띈다. / 해결: ① **1콜 감별법** — `document.body.style.setProperty('color', 'rgb(9,8,7)', 'important')`를 건 뒤 곧바로 computed를 읽는다. 인라인 `!important`가 **안 먹으면** 캐스케이드 문제가 아니라 **관측 경로가 얼어붙은 것**이다(강제 layout `offsetHeight`로도 안 풀린다 — 스크린샷으로 페인트를 강제해야 풀린다). ② 결정적 물증은 **보간 중간값**이었다: 운영 번들에서 재니 `main`이 `rgb(23,26,28)`, 즉 검정(0,0,0)과 `#212529`(33,37,41) 사이의 딱 70% 지점이었다 — 시작값도 최종값도 아닌 값은 **트랜지션 말고는 나올 데가 없다**. ③ 근본 수정은 정적 css에서 잉크를 확정하는 것이다(`html body { color: var(--adaptiveGrey800, #2C2A24) }`) — 마운트 뒤 색이 **바뀌지 않으니** 트랜지션이 애초에 발화하지 않는다. 로드마다 0.45초 검정→잉크 페이드가 있었다는 뜻이기도 하다(실사용자도 겪던 것). / 재발방지: ① **트랜지션 얼림은 「토글을 눌렀을 때」만이 아니라 「페이지 로드 때」도 난다** — 정적 css가 안 잡는 상속 속성을 런타임 주입 스타일(emotion `<Global>`·CSS-in-JS)이 나중에 바꾸면, 그 자체가 트랜지션 트리거다. T-196의 프레이밍(독서등 켬/끔)만 기억하면 이 경로를 못 떠올린다. ② **얼어붙은 시작값이 UA 기본값(검정·`start`·`auto`)이면 감별 신호가 사라진다** — 「전부 한 값」은 「규칙이 안 먹었다」와 구별되지 않는다. 그래서 비대칭 관찰보다 **위 ①의 인라인 `!important` 프로브를 먼저** 돌린다(1콜, 항상 결론이 난다). ③ **상속 속성에 트랜지션을 걸면 그 속성은 앱 전체의 계측 신뢰도를 떨어뜨린다** — 걸 거면 그 속성의 초기값을 **정적 css에서 확정**해 로드 시 발화를 없앤다. ④ 곁다리 소득이 본전보다 컸다: 이 오진을 파다가 **진짜 결함**이 나왔다 — `<Text color="grey600">` 87곳이 토큰 이름을 넘겨 무효값이 되고 전부 상속으로 떨어져 있었다(흐림 위계가 통째로 없었다). **관측 경로를 의심해 걷어내면 그 밑에 진짜가 있을 수 있으니, 아티팩트로 판명나도 조사를 거기서 멈추지 않는다.** **관련**: T-196(1회차) · T-201·T-184 군(관측 경로가 앱 결함으로 위장) · T-198(TDS를 거치면 소스와 DOM이 다르다)
