## A. 홈

- [ ] **측정 중 홈 — 표지를 남기고 탭을 잠근다** — 측정을 켜면 읽는 책 표지가 남고 하단 탭이 잠기는지. 끄면 풀리는지.
- [ ] **독서등 — 측정 중 홈이 밤이 된다** — 측정 중 홈 배경이 어두워지는지. ⚠️ **여기서 버벅임을 특히 본다** — 애니메이션·합성은 데스크톱·목 모드가 원리상 못 잡는 클래스다(T-176).
- [ ] **홈 피드 「함께 읽는 사람」 탭** — 피드에 탭이 뜨고 사람 목록이 채워지는지.
- [ ] **「함께 읽는 사람」에 마지막으로 읽은 책** — 각 사람 옆에 최근 책이 붙는지.

## B. 서재 · 책방

- [ ] **둘러보기 — 발견 화면** — 책방 검색바를 누르면 전체 화면이 열리고, 들어갈 때마다 얼굴이 바뀌는지. 검색어를 넣으면 기존 아이디 검색이 그 자리에 그대로 나오는지.
- [ ] **실기기 성능 — 책방 격자** — 카드가 수십 개 깔릴 때 스크롤이 매끄러운지.
- [ ] **캐시 렌더** — 재진입이 빨라졌는지. 재검증 응답이 캐시 화면을 덮을 때 **깜빡임·스크롤 점프**가 없는지.

## C. 여백

- [ ] **여백 좋아요** — 남의 문장에 하트가 눌리고 카운트가 오르는지.
- [ ] **여백 좋아요 후속** — 누가 눌렀는지 보이는지. 내 글에도 눌리는지.
- [ ] **여백에 인용문** — 「책의 문장 + 내 주석」 두 층이 제대로 갈라 보이는지.

## D. 기록 · 목표

- [ ] **기록 — 하루에 읽은 책을 더미로** — 날짜를 누르면 펼쳐지며 책별 시간이 나오는지.
- [ ] **화면 밀도 2건** — 요약이 앞으로 나오고 상태가 칩으로 바뀌었는지.
- [ ] **화면 밀도 3건** — 텍스트만 있던 자리에 형태가 생겼는지.

## E. 전역 · 계정

- [ ] **육안 확인 4종** — 스토리 링 · 세그먼트 · **safe-area**(노치·홈 인디케이터에 안 물리는지) · 기록 탭 초기 스크롤 위치.
- [ ] ⚠️ **탈퇴 성공 경로** — **아직 아무도 끝까지 밟아 본 적 없는 유일한 구간**이다. 탈퇴가 실제로 완료되는지.
      ※ 계정이 사라지므로 **다른 항목을 전부 끝낸 뒤 마지막에** 한다.
