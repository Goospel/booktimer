# BookTimer — 한국 저작권 등록 가이드

> BookTimer(웹서비스/소프트웨어)를 한국에서 **컴퓨터프로그램 저작물**로 저작권 등록하기 위한
> 조건·서류·절차·비용 정리. 분쟁 대비(증거 확보)가 목적이며, 실행 전 한국저작권위원회
> 무료 상담(**1800-5455**)을 한 번 받는 것을 권장한다.
>
> 조사일: 2026-06-04 · 수수료/서식은 변동될 수 있으니 신청 직전 [CROS](https://www.cros.or.kr/)에서 재확인.

---

## 0. 전제 — 등록은 "권리 발생"이 아니라 "증거 확보"

한국은 **무방식주의**라 저작권은 코드를 만든 순간 자동으로 발생한다. 등록을 안 해도 저작권은 이미 우리 것.
등록하는 이유는 **분쟁 시 입증 부담을 덜고 추가 보호를 받기 위해서**다.

### 등록의 법적 효과

| 효과 | 내용 |
|---|---|
| **추정력** | 등록된 자가 저작자로, 등록일이 창작일로 **추정** → 상대가 반증해야 함(입증책임 전환) |
| **대항력** | 저작권 양도·이전 등 권리변동은 등록해야 제3자에게 대항 가능 |
| **법정손해배상** | 침해 **전에** 등록되어 있으면 실손해 입증 없이 법정손해배상(저작물당 최대 1천만원, 영리·고의 5천만원) 청구 가능 |
| **과실 추정** | 등록 저작물 침해 시 침해자의 과실이 추정됨 |

> ⚠️ 창작 후 **1년이 지나서** 창작연월일을 등록하면 창작일 추정은 적용되지 않는다 → **가급적 빨리 등록**.

---

## 1. 등록 단위 — BookTimer는 무엇으로?

- **백엔드/프론트 소스코드 전체 → "컴퓨터프로그램 저작물"** 로 등록 (핵심)
- UI 화면 디자인·일러스트·로고 → 원하면 **미술저작물**, 사용설명서·문구 → **어문저작물** 로 별도 등록 가능(필수 아님)
- **이름 "BookTimer" 자체의 독점**은 저작권이 아니라 **상표권(특허청 KIPO)** 영역 — 별개 절차.
  서비스명 보호가 목적이면 상표 출원을 따로 검토.

---

## 2. 등록 조건 (자격 요건)

1. **창작성** — 베끼지 않은 독자적 표현. 아이디어·기능 자체가 아니라 그것을 구현한 **소스코드의 표현**이 대상.
2. **신청인 = 저작자**
   - 개인이 혼자 만들었으면 개인 명의
   - **회사 업무로 직원이 만들었으면 법인이 저작자(업무상저작물)** → 법인 명의
   - 외주 개발이면 계약서상 저작권 귀속 주체 확인 필요
3. **오픈소스/서드파티 라이브러리 주의** — Spring, MySQL 드라이버, npm 패키지 등 **남의 코드는 등록 대상 제외**,
   **직접 작성한 부분만** 보호. 명세서 작성 시 이 점 의식(GPL 등 라이선스 충돌도 회피).

---

## 3. 필요 서류

| 서류 | 비고 |
|---|---|
| **프로그램 등록신청서** | 저작권법 시행규칙 별지 제3호의2서식 (위원회 양식 다운로드) |
| **프로그램등록신청명세서** | 명칭·기능·개발언어·창작일 등 기재 |
| **복제물(소스코드)** | 전자적 기록매체(파일) 1부 — 아래 4번 참고 |
| **등록사유 증명서류** | 권리변동(양도 등) 등록 시. 최초 등록이면 보통 불필요 |
| **신분증 사본 / 사업자등록증** | 개인 또는 법인 |
| **위임장** | 대리인(변리사·대행사)이 신청할 경우 |

---

## 4. 소스코드(복제물) 제출 — 영업비밀 보호 포인트

- 전체를 다 낼 필요 없음. 창작 사실을 입증할 수 있으면 **일부 발췌** 제출 가능(실무상 앞·뒤 일부, 수십 페이지 분량).
- **컴파일 전 원시코드(소스 언어 그대로)** 로 제출. 실행파일도 등록 가능하나 입증엔 소스가 유리.
- 핵심 알고리즘 등 민감부는 발췌 범위 조절로 노출 최소화.
- 더 강하게 묶고 싶으면 등록과 **별개**로 위원회의 **소프트웨어 임치(Escrow)** 제도(원시코드·기술정보 보관) 병행 가능.

---

## 5. 등록 절차

```
① 등록상담 → ② 신청서·명세서 작성 → ③ 등록신청 + 수수료 납부
→ ④ 등록심사 → ⑤ 등록부 등재·등록증 교부 → ⑥ 등록공보 발행 → ⑦ 사후관리
```

- **온라인 신청**: 저작권등록시스템 **CROS (www.cros.or.kr)** 회원가입 후 진행(소스코드 파일 업로드)
- **오프라인**: 한국저작권위원회 방문/우편
- 처리 기간 통상 **수 주**. 반려 시 반려일로부터 **1개월 내 이의신청** 가능.

---

## 6. 비용

| 항목 | 금액 |
|---|---|
| 프로그램 등록 수수료 | **60,000원** (온라인 신청 시 **50,000원**) |
| 등록면허세(교육세 포함) | 1건당 **3,600원** |

→ CROS에서 직접 온라인 등록 시 **약 5만 원대**. 변리사/대행사 이용 시 대행료(수십만 원) 추가.
BookTimer 규모면 **본인이 직접 등록**해도 충분.

## 7. 실행 체크리스트

- [ ] 저작자 확정 (개인 vs 법인 업무상저작물)
- [ ] 내가 직접 쓴 코드 / 오픈소스·외주 코드 구분
- [ ] 발췌할 소스코드 범위 정리(영업비밀 고려)
- [ ] CROS 회원가입 → 신청서·명세서 작성 → 소스 업로드 → 수수료 납부
- [ ] (선택) 서비스명 보호 원하면 상표 출원 별도 검토
- [ ] (선택) 핵심코드 임치제도 병행
